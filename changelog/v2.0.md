# Changelog v2.0 — Tái cấu trúc toàn bộ & Nâng cấp UI/UX

**Ngày phát hành:** 2026-06-18  
**Loại:** 🚀 Major Release — Refactor kiến trúc + UI Glassmorphism

---

## Tổng quan

Phiên bản nâng cấp lớn nhất của dự án. Toàn bộ file `app/page.tsx` monolithic (~1600 dòng) đã được tái cấu trúc thành các component độc lập, rõ ràng và dễ bảo trì. Giao diện được nâng cấp toàn diện theo phong cách **Glassmorphism** với hiệu ứng động, gradient và typography hiện đại.

### 🎨 Giao diện — Glassmorphism UI Upgrade

- **Glassmorphism Cards**: Tất cả card dùng `backdrop-blur`, `bg-white/10`, `border-white/20`
- **Gradient Backgrounds**: Background toàn trang dùng gradient nhiều lớp (xanh dương – tím – teal)
- **Floating Orbs**: Hiệu ứng bong bóng gradient nổi phía sau nội dung chính
- **Micro-animations**: Hover effects mượt mà, transition 300ms trên tất cả interactive elements
- **Tab Transition**: Chuyển tab có hiệu ứng fade + slide mượt
- **Modern Typography**: Sử dụng Google Font Inter, cải thiện font-weight hierarchy
- **Responsive Layout**: Tối ưu hoàn toàn trên mobile (375px), tablet (768px), desktop (1280px+)
