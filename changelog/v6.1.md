## 1. ⚡ Font Loading Tối Ưu — Loại bỏ Render Blocking

**Vấn đề:** `globals.css` dùng `@import url('https://fonts.googleapis.com/...')` — đây là một trong những nguyên nhân phổ biến nhất khiến **Largest Contentful Paint (LCP)** bị chậm, vì trình duyệt phải tải xong CSS trước khi mới bắt đầu tải font.

**Giải pháp:**
- Chuyển hoàn toàn sang `next/font/google` trong `app/layout.tsx`.
- Font được tự host bởi Next.js — không còn request đến Google Fonts, tải song song với HTML.
- Thêm `subset: ['vietnamese']` cho Inter để hỗ trợ đầy đủ tiếng Việt có dấu trong bộ ký tự được tải trước (preloaded).
- Sử dụng CSS variables `--font-body` và `--font-heading` để đảm bảo font chain nhất quán.

**Files thay đổi:**
- `app/layout.tsx` — Thêm `Inter`, `Outfit` từ `next/font/google`; thêm `Viewport` export; thêm OpenGraph metadata
- `app/globals.css` — Xóa `@import`, cập nhật CSS vars sang `var(--font-body, ...)`

## 2. 🖼️ Image Optimization — Tự động WebP/AVIF

**Vấn đề:** Hero image trong `HomeTab` dùng thẻ `<img>` thuần — không được tối ưu hóa, không có lazy loading thông minh, không có LCP priority hint.

**Giải pháp:**
- Thay thế `<img>` bằng `<Image>` từ `next/image` với `priority` flag (báo trình duyệt preload ảnh này vì là LCP element).
- `fill` layout + `sizes="100vw"` để Next.js tự tính toán kích thước ảnh phù hợp cho từng màn hình.
- Cấu hình `next.config.mjs`:
  - Thêm `formats: ['image/avif', 'image/webp']` — trình duyệt hỗ trợ tự nhận AVIF (nhỏ hơn JPEG 50%), fallback về WebP.
  - Thêm `minimumCacheTTL: 86400` — cache ảnh remote 24 giờ.

**Files thay đổi:**
- `components/features/home-tab.tsx`
- `next.config.mjs`

## 3. 🔒 Bảo Mật Nâng Cao — Hạn chế Hostname Ảnh

**Vấn đề:** `next.config.mjs` cũ dùng `hostname: '**'` (wildcard) — cho phép Next.js optimize ảnh từ **bất kỳ domain nào**, tạo ra nguy cơ SSRF (Server-Side Request Forgery).

**Giải pháp:** Thay bằng whitelist hostname cụ thể:

```
images.unsplash.com        — Hero images
*.supabase.co              — Ảnh upload từ Supabase Storage
lh3.googleusercontent.com  — Avatar Google OAuth
avatars.githubusercontent.com — Avatar GitHub OAuth
graph.facebook.com         — Avatar Facebook OAuth
```

**Thêm trong cùng lần:**
- `compiler.removeConsole` — Tự động xóa `console.log` trong production build (giữ `error`, `warn`).
- `experimental.optimizePackageImports` — Tree-shaking tốt hơn cho `lucide-react` và `@supabase/supabase-js`, giảm bundle size đáng kể.
- Cache header `Cache-Control: public, max-age=31536000, immutable` cho `/assets/(.*)`.

**Files thay đổi:**
- `next.config.mjs`

## 4. ⚡ React Performance — useMemo & useRef

**Vấn đề:** Trong `page.tsx`, tất cả các giá trị phái sinh (`filteredDevices`, `filteredMaterials`, `categories`, `myLoans`, `myReports`, `pendingLoans`, `activeLoans`, `pendingReports`, `isAdmin`) được tính lại trong phần render — nghĩa là **mỗi khi bất kỳ state nào thay đổi**, tất cả 9 phép tính này đều chạy lại, dù input không đổi.

**Giải pháp:**
- Chuyển tất cả 9 computed values lên đầu component dùng `useMemo`.
- Xóa phần khai báo trùng lặp cuối file (đã tồn tại cả hai bản: memoized ở đầu và non-memoized ở trước `return`).

**Sửa lỗi infinite loop tiềm ẩn trong `loadUserData`:**
- **Root cause:** `loadUserData` được wrap trong `useCallback` với `authUser` trong dependency array → mỗi khi `authUser` thay đổi (ví dụ: session refresh), `loadUserData` được tạo lại → `useEffect` phát hiện dependency mới → gọi `loadUserData` → cập nhật state → trigger lại cycle.
- **Giải pháp:** Dùng `useRef` để lưu giá trị hiện tại của `authUser` mà không tạo dependency. `loadUserData` không còn phụ thuộc `authUser` nhưng vẫn đọc được giá trị mới nhất qua `authUserRef.current`.

**Files thay đổi:**
- `app/[[...slug]]/page.tsx`

## 5. 🔧 Supabase Client Singleton

**Vấn đề:** `createClient()` được gọi mỗi khi module được import — trong Next.js dev mode với hot-reload, điều này có thể tạo ra nhiều instance WebSocket đồng thời, gây cảnh báo và tốn tài nguyên.

**Giải pháp:**
- Sử dụng pattern `globalThis.__supabaseClient` để đảm bảo chỉ có 1 instance duy nhất.
- Thêm cấu hình auth tường minh: `persistSession: true`, `autoRefreshToken: true`, `detectSessionInUrl: true`.

**Files thay đổi:**
- `lib/supabase.ts`

## 6. 🛡️ TypeScript Type Safety

**Vấn đề:** Nhiều nơi trong codebase dùng `err: any` trong catch block và `authUser: any` trong props — mất hoàn toàn type checking cho các lỗi runtime.

**Giải pháp:**
- Tất cả `catch (err: any)` → `catch (err: unknown)` với type narrowing `err instanceof Error ? err.message : 'Lỗi không xác định'`.
- `authUser: any` trong `HomeTab` và `DevicesTab` → `User | null` từ `@supabase/supabase-js`.
- `onOpenAuth` trong `AppHeaderProps`: bổ sung `'forgot' | 'magic'` vào union type (type cũ là `'login' | 'register'` nhưng `page.tsx` thực tế gọi cả 4 mode — đây là type mismatch thực sự).
- `downloadCSV` trong `export.ts`: `any[][]` → `(string | number | null | undefined)[][]`.

**Files thay đổi:**
- `app/[[...slug]]/page.tsx`
- `components/features/home-tab.tsx`
- `components/features/devices-tab.tsx`
- `components/features/profile-tab.tsx`
- `components/layout/app-header.tsx`
- `lib/utils/export.ts`

## 7. 🛠️ Utility Functions Cải Tiến

### `lib/utils/date.ts`
- **Trước:** Manual string padding `String(date.getDate()).padStart(2, '0')`.
- **Sau:** `Intl.DateTimeFormat('vi-VN', { ... })` — tạo một lần (module-level singleton), format theo đúng locale Việt Nam.
- **Thêm:** `relativeTime(value)` — trả về chuỗi tương đối kiểu "3 ngày trước" dùng `Intl.RelativeTimeFormat`.
- **Thêm:** Guard check `isNaN(date.getTime())` — tránh crash khi input không hợp lệ.
- **Fix timezone:** `formatIsoDate` dùng local getters (`getFullYear`, `getMonth`, `getDate`) thay vì `toISOString().slice(0, 10)` để tránh off-by-one ở timezone UTC+7.

### `lib/utils/export.ts`
- **Fix memory leak:** Thêm `setTimeout(() => URL.revokeObjectURL(url), 100)` — URL object URL bị giữ mãi nếu không revoke, gây memory leak trong session dài.
- **Fix regex:** `escaped.search(/("|,|\n)/g)` → `/[",\n].test(escaped)` — cách viết đúng hơn, clear hơn.
- **Fix types:** `any[][]` → `(string | number | null | undefined)[][]`.

**Files thay đổi:**
- `lib/utils/date.ts`
- `lib/utils/export.ts`

## 9. ♿ Accessibility — ARIA Standards

**Vấn đề:** Navigation không có label — screen reader không biết đây là nav chính. Active tab không được đánh dấu cho công cụ hỗ trợ.

**Giải pháp:**
- Thêm `aria-label="Điều hướng chính"` cho `<nav>`.
- Thêm `aria-current="page"` cho tab đang active (chuẩn WAI-ARIA).

**Thêm trong `globals.css`:**
- `.content-auto { content-visibility: auto; contain-intrinsic-size: 0 500px; }` — browser hint để skip off-screen rendering cho tab panels.

**Files thay đổi:**
- `components/layout/app-header.tsx`
- `app/globals.css`
