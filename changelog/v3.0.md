# Changelog v3.0 — Font tiếng Việt, Nhật ký phân quyền, Nâng cấp Lịch

**Ngày phát hành:** 2026-06-25  
**Loại:** 🚀 Major Release — Font tiếng Việt + Nhật ký phân quyền + Lịch nâng cấp

---

## Tổng quan

Phiên bản v3.0 tập trung vào 5 thay đổi lớn: đổi font hỗ trợ tiếng Việt tốt hơn, xây dựng hệ thống nhật ký phân quyền theo vai trò (học sinh / giáo viên / admin), nâng cấp bộ lọc cho lịch hoạt động, bỏ phần quản lý tài khoản khỏi trang quản trị, và sửa lỗi footer links.

---

## ✅ Tính năng & Thay đổi

### 🔤 Font tiếng Việt — Be Vietnam Pro

- Thay thế **Plus Jakarta Sans** (hỗ trợ dấu TV kém) bằng **Be Vietnam Pro** — font Google thiết kế riêng cho tiếng Việt
- Hỗ trợ đầy đủ dấu tiếng Việt: ă, â, đ, ê, ô, ơ, ư và tất cả dấu thanh
- Cập nhật trong `globals.css` (Google Fonts import) và `tailwind.config.ts` (fontFamily)

### 🔥 Nhật ký phân quyền theo vai trò

Hệ thống nhật ký được thiết kế lại hoàn toàn với 3 loại:

| Vai trò | Tab | Mô tả |
|---|---|---|
| 🎓 Học sinh | Nhật ký buổi học | Ghi chép cá nhân: môn học, nội dung đã học |
| 👨‍🏫 Giáo viên | Đánh giá buổi học | Nhận xét, đánh giá sao (1-5), lớp, môn |
| 👑 Admin | Tình trạng phòng | Ghi tình trạng phòng, ghi chú thiết bị hỏng |

**Tính năng mới:**
- **3 Sub-tabs** trong trang Nhật ký, lọc theo `journal_role`
- **Bộ lọc nâng cao**: tìm kiếm text, lọc theo khoảng ngày, sắp xếp mới/cũ
- **Form ghi nhật ký động**: thay đổi fields tự động theo vai trò người dùng
- **Đánh giá sao tương tác** (tab Giáo viên): click chọn 1-5 sao
- **Badge tình trạng phòng** (tab Admin): Tốt (xanh) / Bình thường (vàng) / Cần sửa chữa (đỏ)
- **Quyền ghi**: HS tự ghi tab HS, chỉ GV/Admin ghi tab GV, chỉ Admin ghi tab Admin
- **Quyền xoá**: Admin xoá tất cả, người viết xoá bài của mình

**Database migration:**
- Thêm 7 cột mới vào `journal_entries`: `journal_role`, `author_id`, `subject`, `room_condition`, `equipment_notes`, `rating`, `target_class`
- Cập nhật RLS policies cho journal

### 📅 Nâng cấp Lịch hoạt động

- **Thanh tìm kiếm** theo tên sự kiện hoặc người phụ trách
- **Bộ lọc thời gian**: Tất cả / Tuần này / Tháng này / Đã qua
- **Badge trạng thái tự động**: 🟢 Sắp tới / 🟡 Hôm nay / ⏳ Đã qua
- **Mini dashboard**: Tổng / Sắp tới / Đã qua
- **Hiển thị số lượng** kết quả tìm thấy

### 🗑️ Bỏ quản lý tài khoản

- Xoá toàn bộ section "Quản Lý Tài Khoản Học Sinh" trong trang Quản trị
- Xoá stat card "Tài khoản học sinh"
- Bỏ state `allProfiles` và query `user_profiles` trong `loadAdminData`
- Lý do: quản lý user trực tiếp tại **Supabase Dashboard → Authentication → Users**

### 🔗 Sửa Footer Links

- Footer đã hiển thị tên tiếng Việt thay vì slug (ví dụ: "Kho Thiết bị" thay vì "co-so-vat-chat")
- Thêm đủ 6 mục điều hướng: Kho Thiết bị, Lịch hoạt động, Nhật ký Lab, Thư viện số, Tin tức, Báo lỗi
- Tất cả links đều chuyển tab đúng khi click

## 📋 Hướng dẫn áp dụng

### 1. Chạy migration SQL

Trong **Supabase Dashboard → SQL Editor**, chạy file `supabase-v3-migration.sql` để thêm cột mới vào `journal_entries`.

### 2. (Tuỳ chọn) Thêm role teacher

Nếu muốn có giáo viên, vào **Supabase Dashboard → Table Editor → user_profiles** và sửa `role` của tài khoản giáo viên từ `'student'` thành `'teacher'`.

---

## ⚠️ Ghi chú

- Migration SQL dùng `ADD COLUMN IF NOT EXISTS` nên an toàn khi chạy lại nhiều lần.
- Dữ liệu nhật ký cũ sẽ có `journal_role = 'quan-tri'` (mặc định) — hiển thị ở tab "Tình trạng phòng".
- Role `teacher` cần được gán thủ công trong Supabase.
